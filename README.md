# Aevora

## Timeless Science. Radiant Skin.

Aevora is a modern skincare e-commerce platform dedicated to helping customers discover high-quality, science-backed skincare products for healthier, more radiant skin. Built with a focus on user experience, performance, and accessibility, Aevora provides a seamless online shopping experience for skincare enthusiasts and beauty-conscious consumers.

🌐 **Live Website:** https://aevora-frontend-uuuc.onrender.com/

⚙️ **Backend API:** https://aevora-backend.onrender.com/

📂 **GitHub Repository:** https://github.com/andahirwe/aevora

## 📖 About Aevora

At Aevora, we believe that great skincare begins with trusted science. Our platform connects customers with carefully selected skincare products designed to support healthy, glowing skin through every stage of life.

## 🚀 Getting Started

### Prerequisites

Before running the project locally, ensure you have:

* Node.js (v18 or later)
* npm or yarn
* MongoDB database connection

### Clone the Repository

```bash
git clone https://github.com/andahirwe/aevora.git
cd aevora
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file in the backend directory:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

### Run the Development Server

Frontend:

```bash
npm run dev
```

Backend:

```bash
npm start
```
